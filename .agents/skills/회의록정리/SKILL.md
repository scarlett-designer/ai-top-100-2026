# 회의록정리

두서없는 회의 메모나 녹음 전사문을 읽고, 결정사항 / 액션아이템 / 담당자 중심으로
구조화된 마크다운 회의록으로 정리한다.

## 입력 처리
- 사용자가 `.txt` 파일 경로를 주면 그 파일을 읽는다.
- 파일 대신 텍스트를 직접 붙여넣은 경우에도 동일하게 처리한다.
- 화자 라벨(`김철수:`, `화자1:`, `[홍길동]` 등)이 있으면 액션 아이템의 담당자 추정에
  활용한다.

## 추출 규칙
- 원문에 없는 내용은 지어내지 않는다. 담당자나 기한이 불명확하면 "미정"으로 표기한다.
- 같은 주제끼리 묶어서 정리한다 (시간 순서가 아니라 주제 순서 우선).
- 잡담이나 중복 발언은 제외하되, 결정의 근거가 되는 맥락은 간단히 보존한다.
- 참석자 목록은 전사문에서 화자가 명확히 드러날 때만 작성하고, 불확실하면 섹션을
  생략한다.
- TL;DR은 아래 섹션들을 나열하는 게 아니라, 회의 전체를 2~4줄로 압축한 요약이어야
  한다 (핵심 주제, 주요 결정, 남은 이슈를 한눈에 파악할 수 있도록).

## 출력 템플릿
다음 구조를 따르되, 해당 내용이 없는 섹션은 "해당 없음"이라고 쓰지 말고 섹션 자체를
생략한다.

```markdown
# 회의록 정리: {제목 또는 날짜 — 추정 가능한 경우}

## TL;DR
- 회의 전체를 2~4줄로 압축한 핵심 요약 (무엇을 논의했고, 무엇이 결정됐는지 중심으로)

## 참석자
- ...

## 결정사항
- ...

## 액션 아이템
| 항목 | 담당자 | 기한 |
|------|--------|------|
| ... | ... | ... |

## 논의사항 / 이슈
- ...
```

## 출력 방식
1. 위 템플릿에 맞춘 마크다운을 채팅에 그대로 출력한다.
2. `ToolSearch`로 `"notion"` 키워드를 검색해 Notion MCP 도구가 연결되어 있는지 확인한다.
   - 도구가 없으면 로컬 파일로 대체 저장한다: 원본 파일과 같은 폴더에
     `{원본파일명}_정리.md`로 저장한다 (붙여넣은 텍스트라 원본 파일이 없으면
     스크래치패드에 `정리결과.md`로 저장). 그리고 사용자에게 Notion MCP 연결이
     필요하다고 안내한다: `Codex mcp add --transport http notion https://mcp.notion.com/mcp`
     (실행 후 브라우저 로그인 인증 필요).
   - 도구가 있으면 3번으로 진행한다 (로컬 파일은 저장하지 않는다).
3. 기본적으로 워크스페이스에 독립된 새 페이지로 생성한다 (parent 지정 없음).
   - 팀 "회의록" DB 등 기존 데이터베이스에는 추가하지 않는다 — 그 DB는 담당자를
     역할로 기록하는 등 자체 컨벤션이 있어 이 스킬의 형식과 맞지 않을 수 있다.
   - 사용자가 특정 부모 페이지를 지정하면 그 위치를 따른다.
4. 위 출력 템플릿을 노션 블록으로 변환해 새 페이지를 생성한다:
   - `# 회의록 정리: ...` → 페이지 제목
   - `TL;DR`, `참석자`, `결정사항`, `논의사항 / 이슈` → 각각 heading + bullet list 블록
   - `액션 아이템` 표 → 노션 테이블(또는 지원되지 않으면 bullet list로 "항목 — 담당자 — 기한"
     형식으로 대체) 블록
5. 생성이 끝나면 노션 페이지 링크를 사용자에게 한 줄로 안내한다.
